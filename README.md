# ngIRCd Homepage

This is the *homepage* of ngIRCd, a free, portable and lightweight Internet
Relay Chat (IRC) server for small or private networks.

The homepage itself can be found on <https://ngircd.barton.de>.

This source code is available on
[GitHub](https://github.com/ngircd/ngircd-web).

## Building

The site is generated by [Zola](https://www.getzola.org/):

```bash
zola serve    # Local preview on http://127.0.0.1:1111
zola build    # Generate the site in public/
```

Content lives in `content/` (Markdown), the layout in `templates/`, and
everything in `static/` is copied as-is. The current release and the download
servers are configured in `config.toml`.

The site must stay fully usable in text-mode browsers like lynx and w3m: no
JavaScript, no content that is only visible with CSS. Check with e.g.
`lynx -dump public/index.html`.

Old URLs of the former PHP site are redirected by `static/.htaccess` (Apache).

## Building the Manual Pages

Use `pandoc` like this:

```bash
pandoc -s -f man -t html -o static/man/ngircd.conf.5.html ../ngIRCd.git/man/ngircd.conf.5
pandoc -s -f man -t html -o static/man/ngircd.8.html ../ngIRCd.git/man/ngircd.8
```

Don't forget to add the updates HTML files to the Git repository!
